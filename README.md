# Stoichiometry Problem Set: Finding Original Molarity

A chemistry problem set where students use **stoichiometry** and the **mass of solid precipitate products** to calculate the **original molarity** of a reactant solution.

## Contents

| File | Description |
|---|---|
| `problem-set.md` | 10 problems of increasing difficulty |
| `answer-key.md` | Complete worked solutions for all problems |

## Learning Objectives

Students will be able to:
- Write and balance precipitation reaction equations
- Convert mass of a solid product to moles using molar mass
- Apply mole ratios from balanced equations
- Calculate molarity from moles and volume
- Chain multiple stoichiometric steps (challenge problems)

## Difficulty Progression

- **Problems 1–4:** 1:1 mole ratios — straightforward application
- **Problems 5–8:** Varied mole ratios — requires careful attention to stoichiometry
- **Problems 9–10:** Challenge problems — multi-step reactions and non-trivial ratios

## How to Use

1. Distribute `problem-set.md` to students
2. Students show all work: balanced equation → moles of product → mole ratio → molarity
3. Use `answer-key.md` for grading or self-check
